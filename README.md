# Orçamento Familiar — iOS

Projeto SwiftUI inicial para gestão de orçamento familiar.

## Funcionalidades
- Dashboard financeiro
- Receitas e despesas
- Categorias
- Orçamento por categoria
- Análise de despesas com gráfico
- Objetivos de poupança
- Elementos da família
- Definições
- Persistência local com UserDefaults

## Requisitos
- Xcode recente
- iOS 17 ou superior

## Como abrir
1. Abra o Xcode.
2. Crie um novo projeto iOS App chamado `OrcamentoFamiliar`, interface SwiftUI e linguagem Swift.
3. Substitua os ficheiros Swift criados pelos ficheiros deste pacote.
4. Adicione `Charts` através do framework Apple Charts (não é necessário pacote externo).
5. Execute no Simulator ou num iPhone.
